# Stress Optimization Reference Survey

Date: 2026-07-22

## 1. Purpose

This document separates three things that are easy to mix together:

1. equations and numerical algorithms that can guide this project,
2. upstream APIs and data layouts that this project must remain compatible with,
3. external source code that must not be copied because its license or ownership
   boundary differs from this repository.

The production target remains restricted PBC DC-DFT stress for PBE/r2SCAN with
GDF/RSDF, Gamma and sampled k-points. External packages are references for work
decomposition and numerical algorithms, not alternate owners of the result.

## 3. Equation and owner map

For a homogeneous strain component $\epsilon_a$, the DC-DFT derivative is
organized as

$$
\frac{d E_{\mathrm{DFA}}[P_{\mathrm{HF}}]}{d\epsilon_a}
= E_a^{\mathrm{explicit}} + Z^T B_a.
$$

The adjoint $Z$ is solved once. The six strain components change only the source
term $B_a$; they do not require six independent orbital-response solves.

| Contribution | Current equation owner | Current code owner | Main optimization question |
|---|---|---|---|
| HF density and orbitals | GPU source RHF | `pbc/gpu` | Reuse the central state; never rerun SCF per component |
| Target Fock and $Z$ | Matrix-free adjoint response | `pbc/gpu/grad` | Share target Fock, AX workspace, and $Z$ with gradient |
| Kinetic and overlap strain | One-electron integral derivative | `stress/cpu` host primitive, GPU contraction | Remove duplicate builds without changing integrals |
| Ewald strain | Analytic lattice derivative | `stress/cpu/ewald_strain.py` | Already small; retain as reference-quality primitive |
| Local GTH PP | AO density strain plus reciprocal chain rule | `stress/gpu/pp_response.py` | Share AO/grid work for source and adjoint densities |
| Nonlocal GTH PP | Projector energy directional derivative | `stress/gpu/pp_response.py` | Batch atoms/channels/densities and avoid 12 repeated projector builds |
| GDF/RSDF $J/K$ strain | 2c/3c source and metric response | `stress/cpu` primitives plus `stress/gpu/df_response.py` | Contract directional derivatives without retaining full derivative tensors |
| Target XC strain | Uniform-grid density strain | GPU4PySCF PBC stress primitive | Reuse AO/grid batches and preserve the exact mesh |
| Final Lagrangian | Six-component device contraction | `stress/gpu/analytic.py` | Keep only Voigt-6 observables on device |

## 4. Transferable strategies

### 4.1 CP2K-style task organization

The transferable idea is to describe work as bounded tasks: grid blocks, atom
projector blocks, reciprocal $G$ blocks, and canonical k-point pairs. Each task
should produce a small contracted observable and release its temporary arrays.
This project keeps PySCF basis ordering, GTH definitions, and GDF/RSDF equations.

### 4.2 Directional derivatives

DC stress needs six scalar contractions, not six complete AO derivative matrix
families. Forward differentiation of a factorization followed immediately by
density contraction avoids retaining a tensor such as
`(6, naux, nao, nao)`.

### 4.3 Hermitian and symmetry reuse

Only canonical k-point pairs are built. Reverse pairs are generated by Hermitian
conjugation, and only the six symmetric Voigt directions are evaluated. This is
an exact algebraic reduction, not screening or an approximation.

### 4.4 Matrix-free adjoint response

The AX matrix is applied as an operator. Krylov iterations store a small number
of vectors instead of a dense orbital Hessian. Preconditioning changes iteration
count but not the target equation or convergence tolerance.

## 5. Candidates and boundaries

| Candidate | Status | Reason |
|---|---|---|
| Fuse source and adjoint PP densities | active | Exact and already supported by the required traces |
| Cache strain-invariant PP structure factors | active | Exact under fixed fractional coordinates |
| Batch nonlocal projector atoms/channels | active | Largest measured PP bottleneck, especially sampled-k |
| Direct-contracted analytic GDF/RSDF response | active | Removes the remaining low-level cell displacement |
| Share gradient/stress $Z$ and target Fock | active | Same central state and adjoint equation |
| CP2K-like adaptive task batches | active as scheduling | Does not change equations or mesh |
| Multigrid stress | deferred | Separate support and accuracy scope |
| Schwarz/locality screening | opt-in research | Needs a rigorous error estimator and fallback |
| Mixed precision | opt-in research | Requires FP64 refinement and stress error evidence |
| Low-rank auxiliary response | opt-in research | Approximation unless rank convergence is demonstrated |
| Copy CP2K/QE kernels | prohibited | Incompatible source-license boundary |

## 6. Measurement contract

Every optimized route must report both ownership and work:

- Python wall time and, when enabled, CUDA-event time,
- AO/grid block count, projector build count, k-pair count, and DF provider count,
- explicit host-to-device and device-to-host payload estimates,
- retained and peak live-workspace estimates,
- exact, contracted, or numerical owner for every contribution.

These fields diagnose scaling. They are not substitutes for process RSS, CuPy
pool usage, or externally sampled global VRAM, all of which remain in benchmark
reports.
