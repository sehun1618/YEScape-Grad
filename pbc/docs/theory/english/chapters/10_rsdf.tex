\section{RSDF: range-separated source and metric response}
\label{sec:rsdf}

\subsection{Purpose of range separation}

Range-separated density fitting (RSDF) uses the exact identity
\begin{equation}
  \frac1r
  =\frac{\operatorname{erfc}(\omega r)}{r}
   +\frac{\operatorname{erf}(\omega r)}{r}
  \equiv v_{\mathrm{SR}}(r;\omega)+v_{\mathrm{LR}}(r;\omega).
  \label{eq:rsdf-range-separation}
\end{equation}
The short-range part decays rapidly in a real-space lattice sum, whereas the
long-range part is readily evaluated as a smooth reciprocal-space sum.  The
infinite sum is independent of $\omega$, but under finite screening and on a
finite mesh, $\omega$ is part of the numerical representation.

\subsection{Source and metric parameters are independent}

The exponent distributions optimized by the three-center source builder and
the two-center metric builder differ, so PySCF RSDF may select different
parameters for them.  Write
\begin{align}
  B^{ij}
  &=B_{\mathrm{SR}}^{ij}(\omega_B,\epsilon_B)
    +B_{\mathrm{LR}}^{ij}(\omega_B,\mathcal G_B)
    +\delta_{\vq,0}B_{vbar}^{ij},
  \label{eq:rsdf-source-split}\\
  M^{\vq}
  &=M_{\mathrm{SR}}^{\vq}(\omega_M,\epsilon_M)
    +M_{\mathrm{LR}}^{\vq}(\omega_M,\mathcal G_M)
    +\delta_{\vq,0}M_0.
  \label{eq:rsdf-metric-split}
\end{align}
In general,
\begin{equation}
  \omega_B\ne\omega_M,
  \qquad \mathcal G_B\ne\mathcal G_M.
  \label{eq:rsdf-independent-parameters}
\end{equation}
Reusing the source parameter for the metric derivative is not a controlled
approximation; it differentiates a different central CDERI.

\subsection{Fixed-cell nuclear derivatives}

Holding the cell, resolved source and metric meshes, $\omega_B$, and
$\omega_M$ fixed gives
\begin{align}
  B^{ij,Ax}
  &=B_{\mathrm{SR}}^{ij,Ax}
    +B_{\mathrm{LR}}^{ij,Ax}
    +\delta_{\vq,0}B_{vbar}^{ij,Ax},
  \label{eq:rsdf-source-derivative}\\
  M^{\vq,Ax}
  &=M_{\mathrm{SR}}^{\vq,Ax}
    +M_{\mathrm{LR}}^{\vq,Ax}
    +\delta_{\vq,0}M_0^{Ax}.
  \label{eq:rsdf-metric-derivative}
\end{align}
The short-range derivative uses the same lattice-image list and screening
precision as the central source or metric.  The long-range derivative uses the
same reciprocal vectors and structure factors.  The integer mesh does not
change under a nuclear derivative.

After Cholesky factorization of the resolved metric,
Eq.~\eqref{eq:gdf-cderi-derivative} applies unchanged,
\begin{equation}
  C^{Ax}=L^{-1}B^{Ax}-L^{-1}L^{Ax}C.
  \label{eq:rsdf-cderi-derivative}
\end{equation}
Both source and metric responses must be retained.

\subsection{The \texorpdfstring{$q=0$}{q=0} correction}

$\vq=0$ does not mean Gamma-only.  A diagonal pair $(\vk_i,\vk_i)$ in a
sampled-k calculation also has $\vq=0$.  Reciprocal equivalence is accounted
for by a test such as
\begin{equation}
  \delta_{\vq,0}
  =\begin{cases}
    1,&\|\vk_j-\vk_i-\vG\|<\epsilon_q
       \ \text{for some reciprocal }\vG,\\
    0,&\text{otherwise}.
   \end{cases}
  \label{eq:rsdf-qzero-test}
\end{equation}
The values and derivatives of source $vbar$, metric $M_0$, and the Ewald
exchange correction must use the same pair orientation.

\subsection{Canonical-pair storage}

Memory can be reduced by storing only canonical $(i,j)$ pairs.  A reverse pair
is reconstructed as
\begin{equation}
  C_{P,\nu\mu}^{ji}
  =C_{P,\mu\nu}^{ij *},
  \label{eq:rsdf-reverse-pair}
\end{equation}
and the derivative must obey
\begin{equation}
  C_{P,\nu\mu}^{ji,Ax}
  =C_{P,\mu\nu}^{ij,Ax *}.
  \label{eq:rsdf-reverse-pair-derivative}
\end{equation}
Transposing the AO indices while omitting the complex conjugate may pass a
Gamma test but produces imaginary leakage and gradient errors at non-Gamma
k-points.

\subsection{Where the RSDF response is used}

As in GDF, the RSDF CDERI derivative enters the explicit target-Hartree
derivative, the source-HF J/K nuclear derivative, and the CPHF source.  The AX
operation applies central RSDF J/K to a transition density.  The complete
structure can be summarized as
\begin{equation}
  g_{Ax}^{\mathrm{RSDF}}
  =g_{Ax}^{1e}+g_{Ax}^{\mathrm H}[C,C^{Ax}]
   +g_{Ax}^{\mathrm{xc}}+g_{Ax}^{\mathrm{Pulay,t}}
   +g_{Ax}^{\mathrm{NN}}+z^\Herm B_{\mathrm{HF}}^{Ax}[C,C^{Ax}].
  \label{eq:rsdf-total-gradient}
\end{equation}

\subsection{The GPU host boundary}

GPU4PySCF currently has no device integral engine that generates all periodic
RSDF two- and three-center derivative primitives.  Central and derivative
integral metadata are therefore generated on the host and transferred to
CuPy.  Metric factorization, $dC$, $dJ/dR$, $dK/dR$, AX/Z-vector operations,
and final assembly then run on the device.  This boundary is recorded in the
metadata and is distinct from a silent fallback to a CPU DC-DFT gradient
kernel.

\subsection{RSDF completion checks}

RSDF validation proceeds in the following order:
\begin{enumerate}
  \item Record the actual provider-resolved $\omega_B$, source mesh,
        $\omega_M$, and metric mesh.
  \item Check value parity between the response builder's central CDERI and
        the SCF storage.
  \item Compare source-only, metric-only, and total $dC$ with component finite
        differences.
  \item Test $dJ/dR$, $dK/dR$, the explicit target term, and the Z response
        separately.
  \item Perform full-energy central finite differences at Gamma and sampled
        k-points.
  \item Check CPU/GPU parity and the translational sum rule.
\end{enumerate}

An empirical correction that becomes small only for a particular molecule
when the auxiliary basis or source/metric mesh is changed is not accepted as
completion evidence.
