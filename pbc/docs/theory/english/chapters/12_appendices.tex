\midrule

At Gamma, the singleton k-axis is retained internally and restored to the
public PySCF shape only at the API boundary.  This prevents Gamma and k-point
implementations from silently adopting different equations.

\subsection{Complex-to-real Hessian blocks}

For a complex response $U=X+iY$, suppose the real-linear map has the form
\begin{equation}
  \delta F(U)=\mathcal A U+\mathcal B U^*.
  \label{eq:appendix-complex-map}
\end{equation}
Its realified operator is
\begin{equation}
  \begin{pmatrix}
    \operatorname{Re}\delta F\\
    \operatorname{Im}\delta F
  \end{pmatrix}
  =
  \begin{pmatrix}
    \operatorname{Re}(\mathcal A+\mathcal B) &
    -\operatorname{Im}(\mathcal A-\mathcal B)\\
    \operatorname{Im}(\mathcal A+\mathcal B) &
    \operatorname{Re}(\mathcal A-\mathcal B)
  \end{pmatrix}
  \begin{pmatrix}X\\Y\end{pmatrix}.
  \label{eq:appendix-real-hessian}
\end{equation}
Production code need not materialize the full four-block matrix; it can supply
the same map through matrix-vector products.

\subsection{Summary of the Cholesky-response gauge}

For $M=LL^\dagger$ and $W=L^{-1}M^{Ax}L^{-\dagger}$, define
\begin{equation}
  \Phi(W)_{ij}
  =\begin{cases}
    W_{ij},&i>j,\\
    \tfrac12W_{ii},&i=j,\\
    0,&i<j.
  \end{cases}
  \label{eq:appendix-cholesky-phi}
\end{equation}
Then $L^{Ax}=L\Phi(W)$.  If the metric is complex Hermitian, diagonal imaginary
noise may be removed within tolerance, but a large anti-Hermitian residual is
an error.

\subsection{A \texorpdfstring{$G=0$ and $q=0$}{G=0 and q=0} checklist}

\begin{enumerate}
  \item The neutral Hartree $G=0$ convention must be identical in the central
        energy and derivative.
  \item Check the constant local-GTH term together with the ionic Ewald charge.
  \item Keep the GDF/RSDF source $vbar$ and metric correction separate.
  \item Diagonal pairs in sampled-k calculations also have $q=0$.
  \item Include the overlap derivative of the exchange
        \texttt{exxdiv='ewald'} correction.
  \item Do not use Gamma-only success as evidence for general $q=0$ handling.
\end{enumerate}

\section{References and reproducibility notes}

PySCF and GPU4PySCF source files and examples are the primary references for
API and tensor conventions.  CP2K source and data provide comparison points
for GTH pseudopotentials, periodic $G=0$ treatment, cutoff/grid behavior, and
force formulations; their GPW and auxiliary-density algorithms must not be
identified with the PySCF GDF/RSDF equations.  When external source code is
consulted, its license and attribution requirements are checked and the
private-API version is retained in result metadata.
